# Пепельные Королевства

Мобильная стратегия в реальном времени в духе *The Battle for Middle-earth*: четыре народа, восемь легендарных героев из истории и мифов, строительство базы, аванпосты, силы народа, бой с ИИ и онлайн с друзьями. Написана на чистом JavaScript + Canvas, без движков и внешних ассетов. Вся графика рисуется процедурно.

![Графика](docs/graphics.png)

## Как играть

Откройте `index.html` в браузере телефона или компьютера. Установка не нужна. Лучше играть в горизонтальной ориентации.

- **Цель:** разрушить цитадель противника.
- **Экономика:** фермы дают золото и лимит армии. Аванпосты (флаги на карте) дают +4 золота/с и +3 к лимиту.
- **Герои** растут до 10 уровня и открывают навыки на 1, 2, 4 и 6 уровне. Павшего героя можно воскресить за полцены.
- **Силы народа** копятся за победы: лечение армии, подкрепление, удар с неба.

## Народы и герои

| Народ | Герой-воин | Герой-маг |
|---|---|---|
| Люди (Камелот) | Король Артур | Жанна д'Арк |
| Эльфы (Сильваэн) | Кухулин | Артемида |
| Гномы (Громгард) | Тор | Фрейя |
| Орки (Чёрный Клык) | Арес | Кощей Бессмертный |

У каждого народа 4 типа войск: пехота, копейщики, стрелки и конница. Копья бьют конницу, конница бьёт стрелков, стрелки бьют пехоту.

## Управление (телефон)

![Управление](docs/controls.png)

- **Касание:** выбрать; касание по земле — идти в атаку; касание по врагу — атаковать.
- **Удержание и ведение пальцем:** рамка выделения. **Два пальца:** зум и прокрутка.
- **Внизу слева:** «Все», «Пехота», «Стрелки», «Конница». Кнопки **1–3** — отряды: удерживайте кнопку, чтобы сохранить отряд.
- **Справа:** круглые кнопки навыков выбранного героя; «АВТО» — герой сам применяет навыки.
- **«Нанять»:** найм из любого здания. **«Держать»**, **«Отступить»**, **«Марш»**.
- **Мини-карта:** касание — камера, двойное касание — отправить войска.

**ПК:** ПКМ — приказ, колесо — зум, ЛКМ с протяжкой — рамка, 1–4 — навыки, Q — вся армия, WASD — камера.

## Онлайн

Онлайн-режим работает, когда игра опубликована как артефакт на claude.ai (он использует комнату `room` платформы). Хост считает игру и рассылает снимки состояния, гости отправляют приказы. Файл `index.html`, открытый напрямую, поддерживает только бой с ИИ.

## Структура

```
src/data.js     народы, войска, здания, герои, навыки, силы
src/engine.js   симуляция: бой, экономика, навыки, аванпосты, снимки для сети
src/ai.js       ИИ-противник
src/net.js      сетевой транспорт и сжатие снимков
src/render.js   процедурная графика: рельеф, спрайты, здания, эффекты
src/main.js     интерфейс, управление, меню, лобби, игровой цикл
src/shell.html  разметка и стили интерфейса
build.sh        сборка в index.html и dist/artifact.html
tests/          автотесты (Node + Playwright)
```

## Сборка и тесты

```bash
./build.sh                  # собрать index.html
node tests/simtest.js       # бои ИИ против ИИ за все расы
node tests/pwtest.js        # сценарий на экране телефона
node tests/uitest.js        # проверка сенсорного управления
node tests/nettest.js       # онлайн: хост и гость в двух вкладках
```

Для тестов в браузере нужен `playwright`.
